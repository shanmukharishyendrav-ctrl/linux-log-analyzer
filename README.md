# Linux Log Analyzer & Security Monitoring System

## Project Description
A Bash-based system to analyze Linux authentication and system logs.

## Features
- Detects failed login attempts
- Identifies suspicious IP addresses
- Summarizes frequent system errors
- Generates security reports
- Automates log analysis using Cron
- Uses Git for version control

## Technologies Used
- Linux
- Bash
- AWK
- Grep
- Sed
- Cron
- Git

## How to Run

```bash
./scripts/analyze_logs.sh
./scripts/suspicious_ips.sh
./scripts/error_summary.sh
./scripts/generate_report.sh
